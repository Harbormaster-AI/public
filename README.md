# Public Assets

## Models
Available domain models.  Modify to your requirements and publish to Harbormaster to use for system generation.

## Docker 
docker-compose.yml : self-contained declarations to run Harbormaster  
.env : environment variables used to configure Harbormaster

``` Requires a harbormaster license file.```

## System-as-Code
Example YAML files to illustrate how to declaratively communicate with a Harbormaster instance to generate a system.
